\## 📌 Einstieg



mosaik.live ist die sichtbare Ebene eines Systems.



OSAI beschreibt, wie aus Information Struktur entsteht.



Nicht durch Zahlen,

sondern durch Bedeutung.



\---



\## 🔄 Grundprinzip



```

INFO → SIGNAL → STRUCT → STATE → OUTPUT

```



OSAI:



```

```

\## 🧠 Was OSAI ist



OSAI ist eine semantische Container-Sprache.



Die kleinste Einheit ist kein Zeichen,

sondern ein Zustand.



Beispiele:



```

ᑕ?ᑐ   = Information

ᑕ˙ᑐ   = Fokus

ᑕ·ᑐ   = Struktur

ᑕ.ᑐ   = Zustand

ᑕ◎ᑐ   = Kern

```



\---



\## 🧩 Systemstruktur



```

raw\_p → LINK2OSAI → CORE → OSAI → mosaik.live

```



\* raw\_p → visuelle Rohstruktur (Archiv, versiegelt)

\* LINK2OSAI → Übergang zur Lesbarkeit

\* CORE → definierte Regeln und Container

\* OSAI → System und Sprache

\* mosaik.live → sichtbare Ausgabe
